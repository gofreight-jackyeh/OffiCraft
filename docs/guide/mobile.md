# 在手機上用控制台

控制台是為手機設計過的。你可以在通勤路上回一張 Ask 卡、看今天誰在忙什麼、把專案往前推——
不需要打開電腦。

## 第一步：讓手機連得到（這一步跑不掉）

**server 只綁 loopback（`127.0.0.1`）。** 這是刻意的：預設不對外，你的資料不會因為裝了它就上網。
所以手機要連，得先有一條你自己開的通道。兩個常見做法：

| 做法 | 適合 |
| --- | --- |
| **tunnel**（例如 cloudflared） | 想從外面／手機也能用：tunnel 給你一個公開 **HTTPS** 網址，配上你設的密碼就能連。tunnel 是你自己開的（我們不代開）；若你走原始碼安裝又已自備 cloudflared，有個選配的 `com.officraft.tunnel` job 可以把它跟 server 一起帶起來 |
| **VPN / Tailscale 這類私有網路** | 只想在自己的裝置之間連，不想開任何公開網址 |

> [!TIP]
> 想從手機／外面用是沒問題的——走一條 tunnel（如 cloudflared，會給你 HTTPS ＋ 你的密碼保護），並設一組夠強的密碼。**別把 server 掛到沒有 HTTPS 的裸公開埠上**：控制台背後就是你的整間工作室。

> [!IMPORTANT]
> **開了對外通道，就把兩步驟驗證一起開起來。**
> loopback-only 的預設之下，密碼是「已經在這台機器上的人」才碰得到的東西；一旦你開了 tunnel，它就變成任何找到那個網址的人都可以對著猜的東西。
> 在座艙右上角的頭像 →〈兩步驟驗證〉可以開啟。畫面會給你一組**設定金鑰**（可直接複製）和一個 `otpauth://` 連結——**沒有 QR code**，這個選單裡不放圖：在手機上直接點那個連結就會跳進驗證器 App（Google Authenticator、1Password、iOS 內建的都行），在電腦上就把金鑰複製過去手動新增。加好之後輸入你的密碼與 App 顯示的驗證碼確認，之後每次登入都要多輸入一組 6 位數驗證碼。
> 登入本身也有煞車：連續失敗幾次之後，下一次嘗試會被擋一段時間（會越擋越久），成功登入就歸零——所以猜密碼這件事在這裡是划不來的。
> 驗證器掉了怎麼辦？在**這台機器上**執行 `ocserverd mfa-disable` 就能關掉——它證明的是「你摸得到這台機器」，跟第一次安裝時那組 claim code 是同一個道理。
> ⚠️ **跑完要重啟 server 才會生效**：那道指令改的是資料庫，而正在跑的 server 是開機時把設定讀進記憶體的，沒重啟就還是會跟你要驗證碼。會用到這條路的人本來就已經被鎖在外面，別讓他以為是這條路壞了。

## 第二步：加到主畫面

連得到之後，用 Safari 打開控制台網址，然後：

1. 點下方工具列的**分享**（方框加向上箭頭）
2. 往下捲，選 **「加入主畫面」**
3. 改一個你認得的名字（例如 `工作室`），按**加入**

之後從主畫面點進去就是**全螢幕**，沒有網址列，用起來跟 App 一樣。

**Android（Chrome）**：右上角選單 › **加到主畫面**，步驟一樣。

控制台已提供名稱、App 圖示與安裝資訊；加到主畫面後會以 OffiCraft 的獨立 App 形式開啟。

## 推播通知

在控制台頂端選 **「開啟通知」**，允許瀏覽器權限後，這台裝置會在新訊息與需要你決定的 Ask 卡到達時收到通知；點通知會回到對應聊天或 Ask 頁。

- 桌面版 Chrome、Firefox、Edge、Safari 與 Android Chrome 都支援。
- iPhone／iPad 需要 **iOS/iPadOS 16.4 以上**，而且必須先依上面的步驟加入主畫面，從安裝的 PWA 開啟後才能啟用推播。
- 若先前封鎖過通知，請到瀏覽器或系統設定中重新允許 OffiCraft。

## 手機上做得到什麼

- **回 Ask 卡** — 問題、背景、選項都在一頁裡，點一下就是決定
- **看任務進度** — 現在在第幾節、卡在哪、卡了多久
- **跟成員聊天** — 包含傳圖與看他們回傳的截圖、設計稿
- **看用量** — 誰在跑、花多少、5 小時與 7 天的額度還剩多少
